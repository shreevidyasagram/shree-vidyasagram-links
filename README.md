# Shree Vidyasagram Links

A standalone, mobile-friendly link page for Shree Vidyasagram.

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then Save.
4. Add the shop storefront image to this repository using the exact filename `storefront.jpg` to show it as the full-screen background. The page has a dark fallback background until the image is added.

The page is served from `index.html`.
